integration-bus is being provisioned in namespace "{{ .Release.Namespace }}".

Core resources (Postgres, Redis, Kafka, the 6 .NET services) start immediately.
Two post-install Jobs finish the provisioning:
  - integration-bus-kafka-provisioner   (creates all Kafka topics)
  - integration-bus-metabase-driver-setup (downloads the ClickHouse Metabase driver)
Then integration-bus-debezium-registrar registers the 3 Debezium source + 3 ClickHouse sink connectors.

Watch progress with:
  kubectl get pods -n {{ .Release.Namespace }} -w

If you created the cluster with deploy/k8s/kind/kind-cluster.yaml, these are reachable directly
on localhost (host port = docker-compose port + 10000):
